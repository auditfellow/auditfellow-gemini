# AuditFellow

For any internal audit deliverable or question (findings, observations, risks, controls, GenAI audits, data strategy or AI usage documents, workpapers), activate the `auditfellow` skill BEFORE answering. It carries this organization's methodology; the answer must follow it.

If the `auditfellow` skill is not available yet, activate `auditfellow-setup` first: it installs the methodology with the person's AuditFellow key.
